CONTROL, NOT CHAOS

不是多开几个进程。
是完整的 Agent 控制平面。

从一次任务到长期运行的 Agent 集群，每一层都可观察、可限制、可停止。

01 / ROUTING

Adaptive routing

根据成功率、延迟、负载、标签、成本和近期故障，为每个任务选择更合适的 Agent。

◇
02 / SAFETY

Policy first

限制路径、工具、网络、环境变量、运行时间与预算。策略失败不会被静默绕过。

03 / RESILIENCE

Built to recover

持久会话、断路器、排空缩容、原子状态与完整进程树终止。

04 / WORKFLOWS

DAG execution

让独立节点并行，让依赖节点按序执行，并将上游结果安全传递给综合任务。

05 / ANYWHERE

Your fleet, in your pocket

局域网手机面板实时显示 Agent、任务、Token、成本、故障与缓存，并支持受保护的取消和关闭操作。
